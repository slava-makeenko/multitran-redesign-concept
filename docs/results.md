## Как мерили

Так же, как «до», чтобы сравнение было честным.

- **Страницы:** главная и страница слова «approach». У оригинала — `multitran.com` и `m.exe?s=approach&l1=1&l2=2`, у концепта — `/` и `/en-ru/approach/`. Статья концепта учебная: 33 перевода в 7 тематиках против ~790 ссылок у оригинала.
- **Lighthouse 12.8.2** — та же версия, что «до», в локальном Chrome:
  - телефон — стандартная эмуляция Lighthouse: медленный 4G и замедленный процессор;
  - десктоп — пресет `desktop`;
  - по три прогона на страницу и форм-фактор, в таблицах медиана;
  - концепт мерили на живом сайте (GitHub Pages) 25.10.2026, оригинал — 23–24.10.2026.
- **Два варианта концепта:**
  - без рекламы — что даёт сама вёрстка;
  - `?ads=sim` — через секунду в каждое место под рекламу приходит «реклама», как от рекламной сети. Проверяет, что поздняя реклама не сдвигает страницу. Настоящие рекламные сети не подключались.
- **axe-core 4.14**, правила WCAG 2.2 A/AA и рекомендации — те же, что в тестах. Оригинал и концепт проверены одним скриптом `tools/axe-compare.mjs` 25.10.2026, на 390 и 1280 px.
- **Вёрстка** — `tools/shots.mjs` на 390 и 1280 px, теми же замерами, что в аудите.

## Что дал редизайн, а что нет

- **Вёрстка, доступность, стабильность — да.** Страница помещается в экран, всё доступно с клавиатуры и скринридера, поздняя реклама ничего не сдвигает. Это заслуга вёрстки, и это сохранится на настоящем сайте.
- **TBT честно сравнивать нельзя.** У оригинала 1,5–1,8 с блокировки — почти целиком рекламные сети ([аудит](audit.md#вес-страницы-свой-код-против-стороннего)), у концепта их нет. 22–47 мс — цена самой вёрстки и фреймворка. Настоящая реклама добавит своё, если не грузить её после первого взаимодействия или только когда место видно на экране.
- **LCP на телефоне — 1,5 с**, ровно в бюджете. Сеть разная: GitHub Pages с CDN против сервера Мультитрана. Поэтому в выводах опираемся на TBT, CLS, доступность и вёрстку, а не на сетевые тайминги.
- **CLS 0,002–0,007, а не ноль.** Единственный сдвиг — заголовок главной, когда Golos Text приходит на смену запасному шрифту. Это в 14 раз ниже порога «хорошо» (0,1) и укладывается в бюджет 0,02.
- **Объём статьи разный.** В учебной статье 33 перевода, у оригинала — около 790 ссылок. DOM 2466 → 902 элемента. Структура — тематики свёрнуты, фильтр, вкладки — рассчитана на большие статьи, но настоящая страница будет тяжелее учебной.
- **Что осталось в предупреждениях Lighthouse:**
  - кеш на 10 минут — так настроен GitHub Pages;
  - неиспользуемый JS — часть рантайма Next.js;
  - полифилы `nomodule` для старых браузеров — современные их не скачивают;
  - блокирующий CSS — один небольшой файл.

## Как повторить

```bash
npm ci
NEXT_PUBLIC_BASE_PATH=/multitran-redesign-concept npm run build
npm run test:e2e          # Playwright и axe
npm run test:budget       # JS первой загрузки
npm run test:lighthouse   # Lighthouse CI с бюджетами
node tools/axe-compare.mjs out.json "home=https://slava-makeenko.github.io/multitran-redesign-concept/"
node tools/record-demo.mjs https://slava-makeenko.github.io/multitran-redesign-concept/ docs/demo.webm
```

Lighthouse «до» и «после» — `lighthouse` 12.8.2 из npm: телефон без флагов, десктоп с `--preset=desktop`, категории performance, accessibility, best-practices и seo. Сводка трёх прогонов — `tools/lighthouse-summary.mjs`.
