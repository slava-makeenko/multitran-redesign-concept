# Мультитран — концепт редизайна

Неофициальный концепт редизайна для портфолио. С Мультитраном не связан, переводы в макетах учебные.

**Сайт:** https://slava-makeenko.github.io/multitran-redesign-concept/ — в работе, обновляется с каждым push в `main`.

- [Аудит «до» и решения концепта](docs/audit.md)
- [План реализации](docs/plan.md): стек, структура, анимации, публикация, замер «после»
- [Сравнение «до / после»](docs/compare.png)
- Макеты: [главная](design/mockups/home.html) и [страница слова](design/mockups/term.html) — адаптивная вёрстка, снимки на 390 и 1280 px в `design/mockups/*.png`
- Снимки оригинала и сводка Lighthouse — `docs/before/`
- Скрипты замеров — `tools/` (снимки и замеры вёрстки через Chrome DevTools Protocol, сводка прогонов Lighthouse)

## Запуск

Нужен Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Разработка на `localhost:3000` |
| `npm run build` | Статическая сборка в `out/`; для GitHub Pages — с `NEXT_PUBLIC_BASE_PATH=/multitran-redesign-concept` |
| `npm run lint` | ESLint |
| `npm run typecheck` | Типы маршрутов и TypeScript |
| `npm run format:check` | Prettier |
| `npm run test:e2e` | Playwright и axe по собранному `out/`: 1280 и 390 px |
| `npm run test:budget` | JS первой загрузки по HTML сборки — не больше 160 КБ gzip на страницу |
| `npm run test:lighthouse` | Lighthouse CI с бюджетами из плана, отчёты — в `.lighthouseci/reports/` |

Тесты идут по статической сборке под тем же подпутём, что на Pages: сначала `npm run build` с `NEXT_PUBLIC_BASE_PATH=/multitran-redesign-concept`. Сайт для тестов отдаёт `tools/serve-pages.mjs` — копия поведения GitHub Pages: подпуть, 404, gzip и правильные типы файлов. Локально Playwright берёт установленный Chrome, в CI — свой Chromium.

CI (`.github/workflows/ci.yml`) на каждый push проверяет линтер, типы и форматирование, собирает сайт, гоняет Playwright, axe и Lighthouse CI и только после этого публикует на GitHub Pages из `main`. Отчёты тестов — артефакт `test-reports`. Публикация работает только у публичного репозитория: на бесплатном тарифе Pages для приватных недоступен.

Lock-файл обновляется через ручной workflow **Lockfile**: npm на Windows не записывает опциональные wasm-зависимости, и `npm ci` на Linux падает. Workflow пересобирает `package-lock.json` на ubuntu и отдаёт его артефактом.

## Статус

Готовы этапы 1–7 из 8 по [плану](docs/plan.md):

1. Каркас на Next.js 16 со статическим экспортом, токены и шрифты из макетов, шапка, подвал, плашка «концепт», страница «О концепте», 404, CI и публикация.
2. Страница слова [approach](https://slava-makeenko.github.io/multitran-redesign-concept/en-ru/approach/) по макету, пока без интерактива:
   - заголовок и вкладки частей речи;
   - основные значения, фильтр тематик;
   - тематики сворачиваемыми группами;
   - боковая колонка и места под рекламу.

   Статьи лежат в `data/entries/` как типизированные модули (`lib/types.ts`), счётчики считаются из данных.

3. Интерактив страницы слова:
   - вкладки «Существительное», «Глагол», «Фразы», «Форум» по WAI-ARIA: стрелки, Home и End; выбранная вкладка хранится в адресе (`?pos=verb`);
   - тематики сворачиваются, «Показать ещё» и «Ещё N тематик» переводят фокус на первое открытое;
   - фильтр тематик: чипы на десктопе, шторка с чекбоксами на телефоне; выбор хранится в адресе (`?s=aviation`), итог объявляется скринридеру;
   - копирование перевода с подтверждением, произношение через синтез речи браузера (кнопка скрыта, если голоса нет);
   - мобильное меню в нижней шторке.

   Шторки сделаны на нативном `<dialog>`: фокус удерживается внутри, Esc закрывает, фокус возвращается на кнопку. Содержимое всех вкладок есть в статическом HTML.

4. Поиск и пять статей: approach, due diligence, «заход на посадку», lead time, approval.
   - Подсказки со второго символа: статьи, фразы (ведут на вкладку «Фразы») и обратный поиск по значениям — «одобрение» находит approval.
   - Комбобокс по WAI-ARIA 1.2: стрелки, Enter, Esc; первая подсказка подсвечена — её откроет Enter; число подсказок объявляется скринридеру.
   - Направление EN ⇄ RU переключается кнопкой и само по алфавиту запроса.
   - Опечатки: «Возможно, вы искали» по расстоянию Дамерау — Левенштейна.
   - История — последние 5 открытых статей в `localStorage`, с кнопкой «Очистить» и защитой от недоступного или испорченного хранилища.
   - Страница `/search/` для запросов без подсказок; без JS форма ведёт туда же, а список всех статей есть в HTML.

   Индекс поиска собирается из тех же данных, что и страницы (`lib/search.ts`).

5. [Главная](https://slava-makeenko.github.io/multitran-redesign-concept/) по макету:
   - большой поиск: полные названия языков и кнопка «Найти», на телефоне — столбиком;
   - «Популярные словари», место под рекламу 728 × 90 (на телефоне 320 × 100), «Тематики», «Сейчас обсуждают на форуме».

   Ссылки ведут в реальные разделы концепта, а не в пустоту:
   - карточка англо-русского словаря — на оглавление [`/en-ru/`](https://slava-makeenko.github.io/multitran-redesign-concept/en-ru/);
   - тематика — на статью, где у неё больше всего переводов, сразу с фильтром;
   - тема форума — на вкладку «Форум» своей статьи.

   Остальные языки и форум ведут на «в концепте не реализовано». Цвета кружков с кодами языков подобраны под контраст белого текста от 4,5:1.

6. Анимации без библиотек — CSS, `@starting-style` и View Transitions:

   | Где | Что | Время | «Уменьшить движение» |
   |---|---|---|---|
   | Подсказки поиска | Проявление со сдвигом на 4 px | 150 мс | Только прозрачность |
   | Группа тематики | Высота через `grid-template-rows: 0fr → 1fr`, поворот шеврона; свёрнутая группа — `inert` | 200 мс | Мгновенно |
   | «Показать ещё N» | Новые строки проявляются по очереди | 150 мс, шаг 20 мс | Мгновенно |
   | Вкладки | Одно подчёркивание переезжает к выбранной вкладке | 200 мс | Мгновенно |
   | Шторка | Выезд снизу и затемнение; закрытие быстрее | 250 / 200 мс | Только прозрачность |
   | Уведомление | Появление снизу и уход | 200 мс | Только прозрачность |
   | Чипы и кнопки | Сжатие при нажатии | 120 мс | Без сжатия |
   | Главная → статья | Слово из чипа или подсказки «перелетает» в заголовок | 250 мс | Без перехода |

   Анимируются только `transform`, `opacity` и высота через `grid-template-rows`; длительности и кривые — токены `--dur-*` и `--ease-*` в `app/globals.css`. Без View Transitions API страница открывается без анимации, без `@starting-style` шторка открывается сразу.

7. Тесты в CI, без них сайт не публикуется:
   - **Playwright**, 125 проверок на 1280 и 390 px: поиск (стрелки, Enter, Esc, история, опечатки, смена направления), вкладки с клавиатуры, сворачивание групп, «Показать ещё» с переводом фокуса, фильтр и шторка (фокус внутри, Esc, возврат фокуса), копирование в буфер, меню, 404, переход «чип → заголовок», режим «уменьшить движение».
   - **axe** (WCAG 2.2 A/AA и рекомендации) на 10 страницах и в открытых подсказках, шторке и меню — 0 нарушений.
   - **Вёрстка**: нет горизонтальной прокрутки, в том числе на 320 px; нет целей нажатия меньше 24 px; один `h1`; нет `tabindex > 0`.
   - **Lighthouse CI**, телефон, медиана трёх прогонов: все категории ≥ 95, TBT ≤ 150 мс, CLS ≤ 0,02, шрифтов ≤ 4. Сейчас: 97 / 100 / 96 / 100, TBT 26–46 мс, CLS 0.
   - **JS первой загрузки** — `tools/js-budget.mjs` по HTML сборки: ≤ 160 КБ gzip на страницу, сейчас 143–147 КБ, из них 137,6 КБ — рантайм Next.js и React.

   Что нашли тесты и что исправлено:
   - логотип: имя ссылки не содержало видимый текст (WCAG 2.5.3) — буква в значке теперь рисуется в CSS;
   - плашка «концепт» была вне областей страницы — теперь `aside`;
   - серый текст (`--muted`) давал 4,0–4,3 : 1 на чипах и подсветке — токен затемнён до 4,6 : 1 и выше;
   - на 320 px строка фильтра выходила за экран — подпись переносится;
   - данные словаря попадали в клиентский JS — индекс поиска собирается при сборке;
   - знаки транскрипции тянули пятый файл шрифта — они набраны системным шрифтом.

   Бюджеты JS и LCP уточнены после первой сборки — почему, в [плане](docs/plan.md#7-бюджеты-производительности).
