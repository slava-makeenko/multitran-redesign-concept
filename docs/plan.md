# План реализации

Концепт по утверждённым макетам: [главная](../design/mockups/home.html) и [страница слова](../design/mockups/term.html). Исходные цифры — в [аудите](audit.md).

## 1. Рамки

**Делаем:**
- главную;
- страницы слов для пяти статей: `approach`, `approval`, `lead time`, `due diligence` и русское «заход на посадку» — чтобы поиск, переключение пары и маршруты работали по-настоящему, а не на одной странице;
- 404;
- поиск с подсказками;
- вкладки частей речи, сворачиваемые тематики, фильтр (чипы и шторка);
- копирование перевода, произношение;
- места под рекламу;
- анимации;
- публикацию;
- замер «после».

**Не делаем:**
- форум;
- вход;
- добавление перевода — кнопка ведёт на заглушку «в концепте не реализовано»;
- реальный backend;
- тёмную тему (можно позже, около 2 ч).

Статьи учебные, составлены для концепта; контент Мультитрана не копируем.

## 2. Стек

| Что | Выбор | Почему |
|---|---|---|
| Фреймворк | **Next.js 16**, App Router, статический экспорт (`output: 'export'`) | Страницы слов — это контентный сайт: HTML собирается заранее, поисковикам и первой отрисовке не нужен JS. Next.js — в позиционировании на FL.ru; кейс показывает SSG, маршруты и метаданные |
| UI | React 19, TypeScript | Интерактив — островками: поиск, вкладки, фильтр, шторка |
| Стили | CSS Modules и токены из макетов (`design/mockups/styles.css`) | Макет переносится один в один; без Tailwind и UI-кита — меньше CSS и зависимостей |
| Шрифты | `next/font`: Golos Text и PT Serif, кириллица и латиница | Шрифты собираются в сборку — без запросов к Google и без сдвигов при загрузке |
| Анимации | CSS-переходы и Web Animations API, без библиотеки | Для коротких переходов хватает CSS; framer-motion добавил бы ~30 КБ JS |
| Данные | JSON-файлы в репозитории, индекс поиска собирается при сборке | Статический сайт, без сервера |
| Тесты | Playwright и `@axe-core/playwright` | Сценарии с клавиатуры и автоматическая проверка доступности |
| Публикация | GitHub Pages через GitHub Actions | Как демо Ledgerline: бесплатно, адрес не похож на multitran.com |

**Рассматривал Astro 7:** по умолчанию ещё меньше JS. Но кейс должен подкреплять React/Next.js-оффер, а с бюджетами из раздела 7 Next.js тоже даёт высокий Lighthouse.

## 3. Структура

```
multitran-redesign/
  app/
    layout.tsx            шрифты, плашка «концепт», шапка, подвал, noindex
    page.tsx              главная
    [pair]/[word]/page.tsx  страница слова; generateStaticParams из data/
    not-found.tsx
    globals.css           токены и базовые стили
  components/
    search/               SearchBox (комбобокс с подсказками), LanguagePair
    entry/                EntryHeader, PosTabs, MainSenses, SubjectFilter,
                          SubjectGroup, TranslationRow, Aside
    ui/                   Button, Chip, BottomSheet, Toast, AdSlot
  lib/                    загрузка статей, индекс поиска, useReducedMotion
  data/                   entries/*.json, subjects.json, pairs.json
  e2e/                    сценарии Playwright и проверка axe
  design/  docs/  tools/  уже есть: макеты, аудит, скрипты замеров
```

**Модель статьи** (`data/entries/approach.json`):

```ts
type Entry = {
  word: string; pair: 'en-ru' | 'ru-en'; ipa?: string;
  pos: { name: 'Существительное' | 'Глагол' | 'Фразы';
         mainSenses: { t: string; gloss?: string }[];
         groups: { subject: string; items: Translation[] }[] }[];
  phrases: { src: string; dst: string }[];
};
type Translation = { t: string; gloss?: string; example?: [string, string]; author?: string };
```

Счётчики (24 перевода, 7 тематик) считаются из данных, а не пишутся руками, — как в макете, но без шанса разойтись.

## 4. Поведение компонентов

- **Поиск.**
  - Комбобокс по WAI-ARIA 1.2: подсказки открываются со второго символа.
  - Стрелки, Enter и Esc работают как в макете; в подсказке — первый перевод.
  - История — последние 5 запросов в `localStorage`, с защитой от недоступного хранилища.
  - Переключатель пары меняет языки местами без перезагрузки.
- **Вкладки частей речи:** `role="tablist"`, переход стрелками; выбранная вкладка в адресе (`?pos=verb`), так что ссылкой можно поделиться.
- **Тематики:** заголовок `h2` с кнопкой `aria-expanded`. Первые две группы открыты, в каждой видно по 6 переводов, кнопка «Показать ещё N».
- **Фильтр:**
  - на десктопе — чипы;
  - на телефоне — `BottomSheet` с флажками: диалог, фокус внутри, Esc и затемнение закрывают, прокрутка страницы на время блокируется;
  - кнопка «Показать N переводов» считает переводы на лету;
  - выбранные тематики в адресе (`?s=aviation,general`).
- **Копирование:** Clipboard API, уведомление «Скопировано» на 2 с с `role="status"`; если буфер недоступен — выделить текст.
- **Произношение:** `speechSynthesis` браузера с английским голосом; без голоса кнопка скрыта. Своих аудиофайлов нет.
- **Места под рекламу:** `AdSlot` с размерами 300 × 250, 320 × 100, 728 × 90 и подписью «Реклама». Режим `?ads=sim` через секунду кладёт в слоты «рекламу» — для проверки, что вёрстка не сдвигается.

## 5. Анимации

| Где | Что | Длительность и кривая | При «уменьшить движение» |
|---|---|---|---|
| Подсказки поиска | Появление: прозрачность и сдвиг на 4 px | 150 мс, `cubic-bezier(0.2, 0, 0, 1)` | Только прозрачность |
| Группа тематики | Раскрытие через `grid-template-rows: 0fr → 1fr`, поворот шеврона | 200 мс | Мгновенно |
| «Показать ещё N» | Новые строки проявляются по очереди, задержка 20 мс | 150 мс | Мгновенно |
| Вкладки | Подчёркивание переезжает к активной вкладке | 200 мс | Мгновенно |
| Шторка | Выезд снизу и затемнение; закрытие быстрее | 250 / 200 мс | Только прозрачность |
| Чипы и кнопки | Фон при наведении, лёгкое сжатие при нажатии | 120 мс | Без сжатия |
| Уведомление | Появление снизу и уход | 200 мс | Только прозрачность |
| Главная → слово | View Transitions API: слово из подсказки «перелетает» в заголовок | 250 мс | Без перехода |

Правила:
- анимируются только `transform` и `opacity`;
- высота анимируется через `grid-template-rows`, а не `height: auto` в JS;
- длительности и кривые — токены `--dur-*` и `--ease-*`, как в Ledgerline;
- где нет View Transitions API, переход просто не анимируется.

## 6. Доступность

- Порядок заголовков `h1 → h2`. Ссылка «К содержимому» — первой на странице.
- Видимый фокус для всех интерактивных элементов, ни одного `tabindex` больше 0.
- Контраст текста — от 4,5:1, у крупного — от 3:1.
- Целей касания меньше 24 px — 0. На телефоне основные — от 44 px.
- У полей есть подписи (видимые или `aria-label`). Иконки-кнопки подписаны.
- Сайт работает с клавиатуры от начала до конца: поиск, вкладки, группы, шторка.

## 7. Бюджеты производительности

Проверяются в CI на каждой сборке — Lighthouse CI, `lighthouserc.cjs`; LCP — замером живого сайта.

| Метрика | Бюджет | Было (телефон, страница слова) |
|---|---|---|
| Lighthouse, все 4 категории | ≥ 95 | 60 / 64 / 75 / 92 |
| LCP (телефон) | ≤ 1,5 с — замер живого сайта, этап 8 | 1,6 с |
| TBT (телефон) | ≤ 150 мс | 1762 мс |
| CLS | ≤ 0,02, в том числе в режиме `?ads=sim` | 0,123 |
| JS первой загрузки | ≤ 160 КБ gzip (план был 130 КБ) | — |
| Шрифты | ≤ 4 файла, `font-display: swap` и подогнанные метрики | — |

**Уточнено на этапе 7, после первой сборки:**
- **JS.** Рантайм Next.js 16 и React 19 с общим каркасом занимает ~137 КБ gzip, поэтому 130 КБ недостижимы без отказа от App Router. Бюджет — 160 КБ: так он ловит рост собственного кода (сейчас 145–156 КБ вместе с предзагрузкой главной). Заодно данные словаря убраны из клиентского JS: индекс поиска собирается при сборке и передаётся пропом.
- **LCP.** На локальном сервере все файлы приходят раньше первой отрисовки, и симуляция Lighthouse (Lantern) считает их нужными для LCP: 2,5–2,8 с при наблюдаемых 0,1 с. На живом сайте те же страницы дают 1,2–1,7 с. Поэтому LCP проверяется не в CI, а замером живого сайта на этапе 8 — тем же способом, что и «до».

## 8. Публикация

- **Репозиторий** `slava-makeenko/multitran-redesign-concept`. Сначала приватный, публичным — когда готов замер «после».
  - Выяснилось на этапе 1: на бесплатном тарифе GitHub Pages для приватного репозитория недоступен. Поэтому репозиторий открыт сразу (24.10.2026), сайт обновляется с каждым push в `main`.
- **Описание** в README и в описании репозитория: «неофициальный концепт редизайна, не связан с Мультитраном».
- **Коммиты** только от Славы, без строк соавтора.
- **GitHub Actions** на каждый push в `main`:
  1. установка (`npm ci`);
  2. проверка типов и линтер;
  3. сборка;
  4. Playwright и axe;
  5. Lighthouse CI с бюджетами из раздела 7.

  Публикация на Pages — только из зелёного `main`.
- **Адрес:** `slava-makeenko.github.io/multitran-redesign-concept/` (`basePath` в `next.config`).
- **В каждой странице:** `<meta name="robots" content="noindex">` и плашка «неофициальный концепт»; ни одной формы, которая что-то отправляет.

## 9. Замер «после»

Тем же способом, что и «до», чтобы сравнение было честным.

1. **Lighthouse 12.8.2 локально на той же машине:** главная и страница `approach`, телефон и десктоп, по три прогона, медиана — скриптами из `tools/`.
2. **Два варианта:**
   - без рекламы — что даёт сама вёрстка;
   - `?ads=sim` — показывает, что при поздней загрузке рекламы CLS остаётся у нуля.

   Настоящие рекламные сети в концепт не подключаем. В отчёте прямо написать, что TBT оригинала почти целиком из-за них.
3. **Свои замеры вёрстки** `tools/shots.mjs` на 390 и 1280 px:
   - текст за краем экрана;
   - цели меньше 24 и 44 px;
   - заголовки и подписи.
4. **axe:** число нарушений до и после.
5. **Итог:** `docs/results.md` с таблицей «было / стало», новые снимки и `docs/compare.png` по реализации вместо макета, видео 60 с: поиск → слово → фильтр → шторка → копирование.

Оговорка для отчёта: хостинг разный — GitHub Pages против сервера Мультитрана. Поэтому в выводах опираемся в первую очередь на TBT, CLS, доступность и вёрстку, а не на сетевые тайминги.

## 11. Риски

- **TypeScript 7.0** — новый компилятор. Если Next.js 16 с ним не дружит, берём ту версию TypeScript, которую ставит `create-next-app`.
- **Статический экспорт:** `next/image` без оптимизации и нет серверных функций. Нам они не нужны: картинок почти нет, всё на клиенте.
- **`speechSynthesis`:** голоса различаются по браузерам, на части устройств английского голоса нет — тогда кнопка скрывается.
- **View Transitions:** поддерживаются не везде. Без них переход просто не анимируется.
- **Lighthouse локально** зависит от нагрузки машины. Прогоняем без других задач, по три раза, и берём медиану.

- **Название и видимость репозитория:** `multitran-redesign-concept`, приватный до замера «после».
- **Объём:** пять статей (рекомендую) или одна `approach`.
